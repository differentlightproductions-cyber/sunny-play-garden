Privacy Policy

Little Sprout Park · Last updated 5 October 2026

In short: There are no ads, analytics or tracking. Children's play needs no account. Game data stays on the device unless a grown-up turns on optional cloud backup. In the Android app, a grown-up may also choose to send the family recovery code to an email inbox they verify.

Who we are

Little Sprout Park ("the app") is a game collection for young children, published by Toasty Games. Questions about this policy: nicholasolsen22@gmail.com.

What is stored on the device

To let children keep playing where they left off, the app saves the following only on the device it runs on (in the browser or app storage):

  • Player names and the animal picture a grown-up chooses for each player.
  • Game progress: stars, letters practised, garden plants, friends met, coloring pictures, pets and their names, and similar counters.
  • Coloring Book pictures: which colors were used where. A child can save a picture as an image file to their own device; the app never uploads it.
  • Clay Corner pictures and the clay creation a child is working on, kept on the device for each player (an album of pictures, plus the unfinished creation in the browser's local storage). They are not included in cloud backup and are saved to the device's photo gallery only if a grown-up turns that on.
  • Sprout Kitchen photos, kept in a local album for each player. They are not included in cloud backup. If a grown-up enables saving Kitchen photos to the device's photo gallery, new photos are also saved there; the app never uploads them.
  • Settings chosen by a grown-up (sound, voice, daily play-time limit, and so on).
  • Optional voice recordings that a grown-up records in the Grown-ups → Voices screen.

None of this is sent to us or to anyone else unless a grown-up turns on the optional cloud backup below.

Optional cloud backup (grown-ups only)

A grown-up can turn on a backup so that players, stars, drawings and the voice recordings described below can be brought back if a device is lost or replaced, or shared with a second device in the same family. It is off by default and is controlled from the Grown-ups screen, which is protected by a grown-up check.

  • The app makes a random family code. No account or password is required for backup.
  • Everything is encrypted on the device using a key made from the family code before it is sent. The code normally stays on the device. We store only the encrypted data and an identifier made from the code, so we do not read names, progress, drawings or voice recordings. If a grown-up chooses email recovery, the code briefly passes through our server and email provider to their verified inbox. This gives the server the technical ability to derive the encryption key during that request, but we do not fetch or decrypt the backup for email recovery and do not store the code with it.
  • The encrypted copy is stored with Cloudflare, Inc., our hosting provider. We do not use it for anything else, and never for advertising or analytics.
  • A grown-up can delete the cloud copy at any time (Grown-ups → Turn off and delete cloud copy). A backup that has not been used for about 13 months is deleted automatically.

A grown-up can also save a backup file to the device and restore it later. That file is kept only where the grown-up saves it.

Optional email recovery (Android app, grown-ups only)

A grown-up can enter their email address in the Grown-ups screen and ask for a six-digit verification code. We send that code to the address through Resend, our email delivery provider. It expires after 10 minutes and cannot restore a backup by itself. After the grown-up enters it in the app, we email the family code to that same verified inbox. The email address is stored on our server only while verification is pending; afterward we keep only a hash of it with the encrypted backup so another address cannot claim that backup. We do not store the family code on the server. Resend and the email provider process the messages needed to deliver them.

The family code message stays in the grown-up's inbox until they delete it there. Anyone who sees the code can restore the family's cloud backup, so keep the email private. Email recovery is optional and children never need to use it. Deleting the cloud backup also deletes its linked email hash from our server, but does not delete a message already delivered to the inbox.

Microphone

The microphone is used only when a grown-up taps Record in the Grown-ups → Voices screen, so the games can play a family member's voice instead of the device's built-in voice. Recordings are stored on that device and can be deleted at any time from the same screen. They are never sent anywhere unless the optional cloud backup above is on. If it is on, each recording (and the names a grown-up gave the voices, such as “Grandma”) is encrypted on the device with the key made from the family code before it is uploaded, under a scrambled file name, so we cannot listen to it or tell whose voice it is. Turning the cloud backup off and deleting the cloud copy removes the uploaded recordings too. The app never records in the background.

Children

The app is designed for young children to use with a grown-up nearby. We do not ask children for personal information. Settings, adding or removing players, and anything that could leave the app are behind a grown-up check. The app contains no links to other websites, no advertising and no in-app purchases.

Third parties

The app uses no advertising networks, analytics or social sign-in SDKs. The optional cloud backup uses Cloudflare. The optional email recovery uses Resend to deliver messages to the grown-up's email provider. These providers process only the information described above to deliver their services. Fonts and images are included with the app.

How the app is delivered

The Android app contains all of its game files and works fully offline; it goes online only if a grown-up turns on the optional cloud backup or chooses email recovery. The cloud backup (and the web version of the game) is served by our web host (Cloudflare). Like any website, the host may keep standard technical logs such as IP address, time, and browser type for security and to deliver the files. We do not use these logs to identify players.

Deleting information

A grown-up can remove a player or reset progress in Grown-ups → Players. Clearing the app's storage, or uninstalling the app removes its local game data. Pictures a grown-up separately saved or shared outside the app may need to be deleted from the device's photos, downloads or files.
